== Using the Web Terminal

You run all commands in this workshop in the OpenShift Web Terminal. The Web Terminal runs directly in your browser, so no local `oc` or `helm` installation is required.

. Open the OpenShift console by navigating to link:https://{OPENSHIFT_CONSOLE_URL}[https://{OPENSHIFT_CONSOLE_URL}^].

. When prompted, log in with your username `{OPENSHIFT_USERNAME}` and password `{OPENSHIFT_PASSWORD}`.

. Click the command-line terminal icon (*>_*) in the upper-right corner of the console masthead.
+
image::web-terminal-icon.png[Web Terminal icon in the OpenShift console masthead,link=self,window=blank,width=700]

. Click *Start* to launch the terminal session. As a cluster administrator, your terminal always runs in the `openshift-terminal` project, so the project field is preselected and cannot be changed.
+
image::web-terminal-panel.png[Web Terminal start panel in the OpenShift console,link=self,window=blank,width=700]

The Web Terminal is automatically logged in with your user credentials. No `oc login` is required.

When started, the terminal looks like the following:

image::web-terminal-panel2.png[Web Terminal open at the bottom of the OpenShift console,link=self,window=blank,width=700]

[TIP]
====
You can open the terminal in a separate browser window by clicking the arrow in the upper-right corner of the terminal window.

image::web-terminal-panel3.png[Button for opening the Web Terminal in a separate window,link=self,window=blank,width=700]
====

=== Verify your environment

Verify your terminal:

. Check which user you are logged in as:
+
[source,bash,role=execute]
----
oc whoami
----
+
Expected output: Your username (`{OPENSHIFT_USERNAME}`).

. Confirm that you have cluster administrator privileges:
+
[source,bash,role=execute]
----
oc auth can-i '*' '*' --all-namespaces
----
+
Expected output:
+
----
yes
----

. Confirm that Helm is available:
+
[source,bash,role=execute]
----
helm version --short
----
+
Expected output: A Helm client version string, such as `v3.x.y+g...`. The Vault Helm chart requires Helm 3.6 or later.
